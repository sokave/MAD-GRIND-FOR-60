# Лабораторна робота №4

Некрасов Артур Дмитрович, ІПЗ-23-3

## Тема й мета

Опрацювання жестів користувача та реалізація інтерактивної взаємодії в React Native. У цій роботі я створив гру **Clicker** і перевірив, як кілька розпізнавачів жестів взаємодіють на одному елементі.

## Що я реалізував

У застосунку є три вкладки Expo Router. У вкладці **Гра** я додав лічильник, рухомий жетон та повідомлення про останній жест. У вкладці **Завдання** видно прогрес і статус кожної цілі. У **Налаштуваннях** можна переглянути правила, вимкнути підсвічування жетона та скинути прогрес із підтвердженням.

Проєкт створив на Expo SDK 58 через `create-expo-app`, прибрав приклади через `npm run reset-project` і підключив залежності через `npx expo install`. У коді використав хуки Gesture Handler 3, які відповідають обробникам із завдання. Перетягування, масштаб і смуга утримання оновлюються через Reanimated. Окремий провайдер зберігає рахунок, лічильники жестів і налаштування в AsyncStorage.

| Жест | Дія | Результат |
| --- | --- | --- |
| Один дотик | Коротко торкнутися жетона один раз | +1 очко |
| Подвійний дотик | Торкнутися жетона двічі з інтервалом до 250 мс | +2 очки за весь жест |
| Утримання | Тримати палець на жетоні 3 секунди | +5 очок один раз. Під час утримання заповнюється смуга |
| Перетягування | Плавно перемістити жетон | Позиція змінюється в межах поля |
| Швидкий свайп | Зробити короткий різкий рух праворуч або ліворуч, почавши на жетоні | Випадково від +3 до +9 очок |
| Масштабування | Звести або розвести два пальці на жетоні | +4 очки за жест, якщо фактичний розмір змінився щонайменше на 12% |

На сторінці завдань є вісім цілей. Для перших двох потрібно зробити 10 одиночних або 5 подвійних дотиків. Інші цілі перевіряють утримання, перетягування, свайпи в обидва боки, масштабування та набір 100 очок. Для власної цілі потрібно зробити подвійний дотик і завершити трисекундне утримання протягом наступних восьми секунд. Утримання має бути наступним розпізнаним жестом.

Кнопка «Центрувати» повертає жетон до початкової позиції та розміру. Скидання прогресу обнуляє рахунок і завдання та залишає вибране налаштування ефектів.

## Як запустити у WebStorm

1. Розпакуй архів. У WebStorm відкрий папку `lab4`, де лежить `package.json`.
2. Перевір, що встановлено Node.js LTS версії 24.3 або новішої в гілці 24. Потім виконай у PowerShell.

   ```powershell
   npm.cmd ci
   npm.cmd run web
   ```


| Команда | Призначення |
| --- | --- |
| `npm.cmd start` | Запустити Metro й відсканувати QR-код у сумісній із SDK 58 версії Expo Go |
| `npm.cmd run android` | Відкрити гру в уже запущеному Android-емуляторі |
| `npm.cmd run clear` | Перезапустити Metro з очищенням кешу |
| `npm.cmd run tunnel` | Підключити телефон через тунель, якщо запуск через локальну мережу не працює |
| `npm.cmd run typecheck` | Перевірити типи TypeScript |

## Контрольні запитання

1. **Які основні типи жестів надає Gesture Handler?** `Tap` розпізнає короткі дотики, зокрема серії з двох натискань. `LongPress` спрацьовує після заданого часу утримання. `Pan` дає безперервні координати переміщення, `Fling` розпізнає швидкий спрямований рух, `Pinch` вимірює зміну відстані між пальцями, а `Rotation` — зміну кута між ними.
2. **Чим `Pan` відрізняється від `Fling`?** `Pan` викликає `onUpdate` під час руху й дає зміщення, за яким я пересуваю жетон. `Fling` спрацьовує одноразово після розпізнавання швидкого руху в заданому напрямку. У грі свайп нараховує випадковий бонус, а плавне перетягування оновлює позицію. У вебверсії для швидких рухів також перевіряю зміщення й тривалість, якщо розпізнавач Fling не отримав достатньо подій.
3. **Навіщо потрібен `GestureHandlerRootView`?** Він задає кореневий контейнер, у якому Gesture Handler розпізнає жести та визначає зв’язки між розпізнавачами. У мене він обгортає навігацію в `app/_layout.tsx`.
4. **Як поєднати кілька жестів на одному елементі?** `useSimultaneousGestures` дозволяє розпізнавачам працювати паралельно. `useCompetingGestures` дає спрацювати тому, що активувався першим. `useExclusiveGestures` задає порядок пріоритету. Я використав його, щоб одиночний дотик дочекався перевірки подвійного. Для послідовної комбінації зберігаю час подвійного дотику й порівнюю його з моментом завершення утримання.

## Висновки й перевірка

Я налаштував кілька розпізнавачів на одному жетоні. Подвійний дотик дає рівно два очки. Швидкий свайп може пересунути жетон, а зараховується як свайп. Окреме збереження прогресу дозволило перевірити скидання й відновлення після перезавантаження.

У браузері перевірив нарахування очок, обидва напрямки свайпу, перетягування, масштабування двома змодельованими дотиками, усі вісім завдань і налаштування. Також перевірив типи та експорт Expo для Web, Android та iOS. Для демонстрації на телефоні потрібно окремо перевірити поведінку жестів у Expo Go.
