Некрасов Артур Дмитрович, ІПЗ-23-3

## Тема й мета

Робота з локальною файловою системою у React Native. У цій роботі я створив **Файловий менеджер**, щоб перевірити створення, читання, редагування та видалення файлів, навігацію по каталогах і зчитування стану сховища.

## Можливості

- Головний екран показує загальну, вільну й зайняту пам’ять. Кнопка оновлення повторно зчитує статистику й вміст відкритої папки.
- Список `FlatList` показує папки перед файлами. Натискання на папку відкриває її. Кнопка зі стрілкою вгору повертає на один рівень, а натискання на частину шляху відкриває відповідну батьківську папку.
- Кнопки «Нова папка» та «Новий файл» відкривають форми. Для текстових файлів розширення `.txt` додається автоматично, а початковий текст можна залишити порожнім. Повторна назва викликає повідомлення й зберігає введений текст у формі.
- На екрані файлу можна прочитати текст і переглянути назву, тип за розширенням, розмір і час останньої зміни. Кнопка «Редагувати» відкриває його в `TextInput`.
- Кнопка кошика запитує підтвердження. На Android та iOS підтвердження показує `Alert.alert()`. Видалення папки охоплює вкладені файли й папки.

Створив проєкт на Expo SDK 58 командою `npx create-expo-app@latest lab5 --template default@sdk-58`, виконав `npm run reset-project` і підключив `expo-file-system` через `npx expo install`. Екрани каталогу й файлу працюють через Expo Router, а `SafeAreaView` враховує вирізи та системні панелі. Мобільна версія зберігає файли в окремій папці `lab5-files` усередині `Paths.document`. У браузері той самий інтерфейс працює з Origin Private File System (OPFS), а статистика показує квоту та використання сховища сайтом.

## Контрольні запитання

1. **Які основні директорії надає Expo FileSystem?** У сучасному API `Paths.document` містить файли, які застосунок зберігає між запусками. `Paths.cache` призначена для тимчасових даних, які система може очистити за браку вільного місця. У старому API цим шляхам відповідають `documentDirectory` і `cacheDirectory`. `Paths.bundle` дає доступ до ресурсів, запакованих у застосунок.
2. **Які методи використовують для базових операцій?** `Directory.create()` створює папку, а `Directory.list()` повертає її вміст як об’єкти `Directory` та `File`. `File.create()` створює файл. `await file.text()` читає вміст, а `await file.write(text)` записує текст. `delete()` видаляє відповідний файл або папку.
3. **Як отримати метадані й обсяг пам’яті?** `file.info()` повертає, зокрема, `size` у байтах і `modificationTime` у мілісекундах від початку Unix-епохи. Тип я визначаю за розширенням у назві. `Paths.totalDiskSpace` та `Paths.availableDiskSpace` дають загальний і вільний обсяг у байтах. Зайнятий простір обчислюю як різницю між цими значеннями.

## Висновки

Я навчився працювати з класами `File`, `Directory` і `Paths`, відображати вкладені каталоги та оновлювати список після операцій. У Chromium перевірив створення й відкриття файлів, зміни тексту, повторне відкриття після перезавантаження, скасування та підтвердження видалення. Також перевірив TypeScript, ESLint і експорт Expo для Web, Android та iOS. На фізичному пристрої ці сценарії можна пройти за інструкцією вище.
